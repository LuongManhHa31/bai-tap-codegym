[Thực Hành] Cài Đặt SASS bằng npm & SASS CLI

Biên dịch tệp SCSS sang CSS hiện đại, chế độ tự động theo dõi (--watch) và quản lý dự án với SASS CLI

⚡

1. Kiểm tra & Cài đặt SASS

Cài đặt SASS toàn cục nhanh chóng thông qua npm và xác nhận phiên bản hoạt động:

npm install -g sass

sass --version
📁

2. Biên dịch đơn tệp SCSS

Biên dịch trực tiếp từ file SCSS sang CSS sẵn sàng nhúng vào website:

sass scss/styles.scss css/styles.css
🔄

3. Chế độ theo dõi (--watch)

Tự động phát hiện thay đổi và biên dịch ngay lập tức khi lưu file:

sass scss/styles.scss css/styles.css --watch
📦

4. Biên dịch theo thư mục

Biên dịch toàn bộ các file trong thư mục đầu vào sang thư mục đầu ra:

sass scss/:css/ --watch
🎨

5. Tính năng SCSS áp dụng

Trang web này được định kiểu bằng SCSS sử dụng Biến ($variables), Mixin (@mixin) và Cấu trúc lồng nhau (Nesting).

$primary-color: #4f46e5;
🚀

6. Trạng thái thực thi

Node.js: v24.21.0 | npm: 11.19.0 | SASS CLI: v1.105.1.

[Thực hành] Chuyển đổi CSS sang SASS Chuẩn

Tổ chức mã nguồn theo mô hình 7-1 pattern (abstracts, base, layout, components)

Card 1: Khóa học SASS Cơ Bản

Chuyển đổi CSS truyền thống thành SASS giúp tái sử dụng các biến ($variables), gom nhóm các đoạn code thường dùng bằng Mixin (@mixin) và tạo cấu trúc phân cấp trực quan với Nesting.

Card 2: Cấu trúc thư mục chuẩn SASS

Mã nguồn được phân tách khoa học thành các thư mục:
• abstracts/: Chứa _variables.scss và _mixins.scss
• base/: Chứa _global.scss
• layout/: Chứa _container.scss
• components/: Chứa _buttons.scss và _cards.scss
• main.scss: Tập hợp tất cả các partials để biên dịch ra css/main.css.

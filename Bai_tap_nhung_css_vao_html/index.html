Các Cách Nhúng CSS Vào Trang Web

Phần 1: Sử dụng Inline-style (Thuộc tính style trực tiếp trên thẻ)

Tiêu đề với Inline CSS (Màu Đỏ)

Đoạn văn bản này được đổi màu bằng cách sử dụng thuộc tính style="color: #16a085;" trực tiếp trong thẻ <p>.

Phần 2: Sử dụng Internal-style (Thẻ <style> trong phần <head>)

Tiêu đề với Internal CSS (Màu Xanh Dương)

Đoạn văn bản này được đổi màu bằng cách định nghĩa class .internal-paragraph bên trong thẻ <style> tại phần <head> của trang web.

Phần 3: Sử dụng External-style (File style.css riêng biệt liên kết qua <link>)

Tiêu đề với External CSS (Màu Tím)

Đoạn văn bản này được đổi màu từ tệp tin style.css bên ngoài thông qua thẻ <link rel="stylesheet" href="style.css">.

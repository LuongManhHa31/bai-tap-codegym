🌟 Kiến trúc bố cục với CSS Flexbox

Bố cục trang web sử dụng CSS Flexbox giải quyết hoàn hảo bài toán căn chỉnh, chia tỷ lệ chiều rộng và tự động thích ứng với mọi kích cỡ màn hình thiết bị.

📐

1. Container Dọc

Phần tử .container thiết lập flex-direction: column với min-height: 100vh giúp Footer luôn bám đáy trang.

⚖️

2. Phân chia 3 : 1

Khung .main-container dùng display: flex, trong đó .content (flex: 3) và .sidebar (flex: 1).

📱

3. Mobile Responsive

Với @media (max-width: 768px), .main-container chuyển sang flex-direction: column giúp trải nghiệm trên điện thoại mượt mà.

🔍 Bảng phân tích tỷ lệ Flexbox

Thành phần Thuộc tính Flexbox Tỷ lệ / Tác dụng
.container display: flex; flex-direction: column; min-height: 100vh; Bố cục tổng thể xếp dọc, phủ toàn bộ chiều cao trình duyệt
.main-container display: flex; flex: 1; Hấp thụ toàn bộ khoảng trống còn lại ở giữa Header & Footer
.content flex: 3; Khu vực nội dung chính chiếm 75% chiều rộng
.sidebar flex: 1; background: #f4f4f4; Cột thông tin phụ chiếm 25% chiều rộng

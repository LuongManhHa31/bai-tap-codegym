[Thực hành] CSS | Thuộc tính flex-flow

Tìm hiểu thuộc tính viết tắt (shorthand) kết hợp giữa flex-direction và flex-wrap

📌 Tóm tắt kiến thức flex-flow

Cú pháp shorthand: flex-flow: <flex-direction> <flex-wrap>;
Vị trí áp dụng: Chỉ có tác dụng khi đặt ở Flex Container (phần tử cha có display: flex).
Giá trị mặc định: flex-flow: row nowrap;

Ví dụ 1: flex-flow: row nowrap (Mặc định)

Ví dụ bắt buộc 1

Sắp xếp các item nằm trên cùng 1 hàng theo hướng đọc văn bản (từ trái qua phải: 1 → 2 → 3) và không xuống dòng (nowrap).

.container-1 { display: flex; flex-flow: row nowrap; }
1
2
3

Ví dụ 2: flex-flow: row-reverse nowrap

Ví dụ bắt buộc 2

Sắp xếp các item nằm trên cùng 1 hàng nhưng theo hướng ngược lại với hướng đọc văn bản (từ phải qua trái: 3 ← 2 ← 1) và không xuống dòng.

.container-2 { display: flex; flex-flow: row-reverse nowrap; }
1
2
3

Ví dụ 3: flex-flow: row wrap (Mở rộng)

Xuống dòng tự động

Sắp xếp theo hàng từ trái sang phải, nhưng khi kích thước các phần tử vượt quá chiều rộng của container thì sẽ tự động xuống dòng tiếp theo.

.container-3 { display: flex; flex-flow: row wrap; }
